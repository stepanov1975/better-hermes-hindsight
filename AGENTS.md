# Repository instructions

Read `DEVELOPMENT.md` and `CONTRIBUTING.md` before changing code.

## README before release

Always update `README.md` before a release to reflect the functionality being released, including user-visible behavior, configuration, defaults, telemetry/evaluation capabilities, and important limitations. Link detailed documentation where appropriate; changes only to secondary documentation do not replace the README update. Verify README examples against the release candidate before publishing.

Keep private evaluation inputs, model responses, credentials, and local evidence out of Git. Public reports should contain aggregate results only.
