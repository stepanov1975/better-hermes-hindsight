# Better Hermes Hindsight 0.1.0a1

`0.1.0a1` is the first development prerelease of the unofficial `better_hindsight` memory provider for Hermes Agent. It targets unmodified Hermes `0.20.0` / `v2026.8.3` and an external, self-hosted Hindsight 0.8.5 service.

## Highlights

- Current-query recall before the first model call, with fail-open behavior on remote errors.
- Opt-in redacted retention with bounded local admission and asynchronous retryable delivery.
- Stable replace-mode replay and reconstructable multi-segment source metadata.
- Hermes-managed Git plugin lifecycle plus an independently built Python wheel.

## Immutable installation inputs

Download all three release assets into one directory. These are the workflow-built artifacts; do not rebuild the wheel for this installation.

```bash
RELEASE_DIR=/path/to/downloaded/v0.1.0a1-assets
(
  cd "$RELEASE_DIR"
  sha256sum --check SHA256SUMS
)
```

Expected artifact hashes:

```text
ba94a798c34043bca02fb80eb51200ae62e82bde85973c6314da7812de5e7ce4  better_hermes_hindsight-0.1.0a1-py3-none-any.whl
69b7b935d37f38c3ba3a6e34be05891b9fa546bd25d05746a22be676249cdce4  better_hermes_hindsight-0.1.0a1.tar.gz
```

Hermes `0.20.0` does not accept a Git ref in `plugins install`. Clone the exact tag first, verify its commit, and install from that verified local clone:

```bash
EXPECTED_COMMIT=3404516e69d4d9861b04ff9299a2c30a76566158
SOURCE_DIR=$(mktemp -d)
git clone --depth 1 --branch v0.1.0a1 --single-branch \
  https://github.com/stepanov1975/better-hermes-hindsight.git \
  "$SOURCE_DIR"
test "$(git -C "$SOURCE_DIR" rev-parse HEAD)" = "$EXPECTED_COMMIT"
```

Use a named, isolated Hermes profile. Before changing packages, stop every process sharing its
interpreter, not only the selected profile:

```bash
PROFILE=better-hindsight-dev
HERMES_PYTHON="$HOME/.hermes/hermes-agent/venv/bin/python3"
hermes gateway list
# Repeat for every listed profile backed by HERMES_PYTHON:
hermes --profile <profile> gateway stop
if pgrep -af "$HERMES_PYTHON"; then
  echo "Hermes interpreter is still in use; stop those processes first" >&2
  exit 1
fi
```

Then install the downloaded wheel and verified Git checkout:

```bash
uv pip install --python "$HERMES_PYTHON" \
  "$RELEASE_DIR/better_hermes_hindsight-0.1.0a1-py3-none-any.whl" \
  'hindsight-client==0.8.5'
uv pip check --python "$HERMES_PYTHON"

hermes --profile "$PROFILE" plugins install "file://$SOURCE_DIR" --enable
HERMES_BASE="${HERMES_HOME:-$HOME/.hermes}"
PLUGIN_DIR="$HERMES_BASE/profiles/$PROFILE/plugins/better_hindsight"
test "$(git -C "$PLUGIN_DIR" rev-parse HEAD)" = "$EXPECTED_COMMIT"
test -z "$(git -C "$PLUGIN_DIR" status --porcelain=v1)"
rm -rf "$SOURCE_DIR"
```

Configure endpoint, bank, credential, and the remaining settings through the immutable
[configuration guide](https://github.com/stepanov1975/better-hermes-hindsight/blob/v0.1.0a1/docs/configuration.md).
Keep `retain.enabled=false`, select the provider, and verify the stopped profile:

```bash
hermes --profile "$PROFILE" config set memory.provider better_hindsight
hermes --profile "$PROFILE" plugins list
hermes --profile "$PROFILE" config get memory.provider
hermes --profile "$PROFILE" better_hindsight status
hermes --profile "$PROFILE" better_hindsight missions check
```

Leave the profile stopped unless an isolated development canary is separately authorized. Do not
install or select this provider in production.

## Important limitations

- Development prerelease only; no production or production-canary approval.
- External/self-hosted Hindsight **0.8.5 only**.
- One static bank for one explicitly asserted principal; no multi-user router.
- Automatic retention remains disabled until a separately authorized isolated canary.
- Better requires `hindsight-client==0.8.5`; bundled Hindsight requires `0.6.1`, so provider changes in one interpreter require a stopped-process package transition.

## Rollback to bundled Hindsight

Stop every process sharing the Hermes interpreter as shown above. Then restore the bundled provider
and its exact SDK while all profiles remain stopped:

```bash
PROFILE=better-hindsight-dev
HERMES_PYTHON="$HOME/.hermes/hermes-agent/venv/bin/python3"

hermes --profile "$PROFILE" config set memory.provider hindsight
hermes --profile "$PROFILE" plugins remove better_hindsight
uv pip uninstall --python "$HERMES_PYTHON" better-hermes-hindsight hindsight-client
uv pip install --python "$HERMES_PYTHON" 'hindsight-client==0.6.1'
uv pip check --python "$HERMES_PYTHON"
"$HERMES_PYTHON" -c \
  'from importlib.metadata import version; assert version("hindsight-client") == "0.6.1"'
```

Preserve both Hindsight banks and Better's outbox; rollback does not migrate or delete them. To
return to Better later, repeat the immutable acquisition and installation procedure above from the
verified GitHub release assets and exact tag clone. Do not substitute a local rebuild or moving Git
URL.
